ANALYTiC Platform

An Active Learning System for Trajectory Classification

ANALYTiC is an interactive system designed to assist researchers and domain experts in the semantic annotation and classification of movement trajectory data. It leverages active learning techniques to select the most informative samples for labeling, thereby significantly reducing the manual effort typically required in the annotation process.

The platform combines machine learning models with data visual tools, including interactive maps and feature-based charts, to guide users through a systematic, iteration-based labeling workflow. By focusing expert attention on only a subset of chosen trajectories, ANALYTiC enables the creation of high-quality labeled datasets while minimizing time.

Key Features

Active Learning Optimization

Implements advanced active learning strategies—Uncertainty Sampling (UNC), Query-by-Committee (QBC), and Random Sampling (RND)—to identify and prioritize the most informative trajectories for labeling, improving classifier performance while minimizing annotation workload.

Flexible Trajectory Handling

Supports ingestion and processing of diverse spatiotemporal data sources including animal, vessel, and human movement datasets. Includes feature extraction from point-level and trajectory-level characteristics to enable robust classification.

Interactive Visual Interface

Offers a browser-based interface with integrated map and chart views, enabling expert users to visually examine and semantically label trajectories with real-time feedback from feature plots and contextual geospatial markers.

Workflow

Data Selection

Users initiate the process by selecting a trajectory dataset of interest. Datasets may represent wildlife tracking, maritime vessel activity, or human mobility data.

Initial Model Training

The system trains an initial model using a small seed set (e.g., 20 labeled samples), ensuring sufficient class representation to bootstrap the active learning cycle.

Iterative Annotation

Based on the chosen strategy (UNC, QBC, or RND), the system presents a batch of informative trajectories to the user for semantic labeling, followed by model retraining after each batch.

Trained Model Deployment

Once the labeling budget is reached, the final model can be used to classify the remaining unlabeled trajectories, facilitating large-scale automated semantic enrichment.

Applications

Transport and Mobility Analysis

Enables mode-of-transport detection and trajectory classification in urban mobility datasets, including public transit, vehicular trips, and pedestrian activity.

Behavioral and Ecological Research

Facilitates semantic labeling of wildlife trajectories to support studies of migration, foraging, and behavioral patterns across species and environments.

Maritime and Security Surveillance

Detects vessel behaviors such as fishing activity and route anomalies, supporting monitoring, regulation enforcement, and maritime safety applications.

Advantages

Efficiency

Achieves near-fully supervised model performance using significantly fewer labeled examples through intelligent sample selection and retraining cycles.

Cost-Effective

Reduces annotation costs by focusing expert labeling effort only on the most informative samples, maximizing return on each annotation.

Adaptability

Suitable for various domains and classification tasks, and can accommodate different trajectory formats, features, and semantic labeling goals.

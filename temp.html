ANALYTiC Platform

Interactive Active Learning for Semantic Trajectory Classification

ANALYTiC is a web-based interactive tool designed to support users in the semantic annotation of trajectory data using machine learning strategies. It employs Uncertainty Sampling (UNC) and Query-by-Committee (QBC) to reduce manual labeling workload while maintaining classification performance.

About ANALYTiC

ANALYTiC addresses the challenge of labeling large-scale trajectory datasets generated from devices such as GPS trackers and sensors. Manual labeling is time-consuming and resource-intensive. ANALYTiC reduces this burden by selecting only the most informative trajectories for annotation.

The system integrates visual support (map visualizations, feature charts) to guide users through the active learning process, providing an effective interface to improve annotation efficiency. It supports common active learning strategies and a variety of classifiers within a flexible, modular architecture.

Key Features

Active Learning Integration

Uses UNC and QBC to prioritize labeling tasks that yield the highest model improvement.

Visual Annotation Interface

Interactive map and charts for inspecting trajectory and point features during annotation.

Flexible System Design

Implemented with HTML5, JavaScript, Python, and Solr; easily extendable for research.

Use Case Datasets

Animal Tracking

Dataset includes elk, deer, and cattle movement patterns to study behavioral differences.

Maritime Activity

Trajectories from vessels labeled as fishing or non-fishing to monitor maritime operations.

Urban Mobility

Human movement trajectories labeled by transport mode: walking, vehicle, and rail-based.
